# Documentação do Projeto ProtejaJá

Esta pasta centraliza toda a documentação técnica, modelagens, protótipos e materiais de entrega acadêmica do projeto.

---

## 📁 Estrutura desta pasta

### 1. `especificacoes/` (Markdown)
Contém os documentos de especificação em formato texto/Markdown:
* **`DOCUMENTACAO.md`**: Documento de arquitetura, stack tecnológica, segurança, conformidade e banco de dados.
* **`REQUISITOS.md`**: Requisitos funcionais (RF01–RF14) e não funcionais (RNF01–RNF09).
* **`CASOS_DE_USO.md`**: Diagrama e detalhamento dos casos de uso (UC01 a UC08).
* **`WIREFRAME.md`**: Descrição textual da estrutura visual e experiência do usuário (UX).

### 2. `pdf/` (Entregáveis e Apresentação)
Versões compiladas em PDF para submissão e apresentação ao orientador/banca:
* **`DOCUMENTACAO.pdf`**: Documentação técnica completa formatada.
* **`REQUISITOS.pdf`**: Requisitos do sistema.
* **`CASOS_DE_USO.pdf`**: Casos de uso do sistema.
* **`WIREFRAME.pdf`**: Wireframes do sistema.
* **`Como_explicar_wireframe.pdf`**: Guia explicativo de apoio para a apresentação.
* **`BACKUP_UC07_FRASE.pdf`**: Cola/roteiro de fala sobre o caso de uso de visualização de denúncia com anexo protegido por login.

### 3. `wireframes/`
* **`wireframes.html`**: Visualização navegável e interativa dos wireframes das telas do ProtejaJá.

### 4. `diagramas/`
* **`diagrama_carro.html`**: Diagrama de Classes UML demonstrando relações de composição (`Carro`, `Motor`, `Roda`), mantido como artefato complementar de modelagem orientada a objetos.
